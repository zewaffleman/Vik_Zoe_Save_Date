# Art archive

Finished art that isn't currently used by the site. It lives outside
`public/` so it's kept in the repo but never deployed. Move a file back into
`public/assets/…` and reference it in `src/config.js` to use it again.

- `flag/`: the hand-drawn date flag (removed from the landing scene).
- `miis/`: alternate Mii idle renders and older exports.
